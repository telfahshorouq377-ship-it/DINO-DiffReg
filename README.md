
# DINO-DiffReg

**DINO-DiffReg: DINOv3-Guided Weakly Supervised Diffusion Registration for Multimodal Medical Images**

## Overview

DINO-DiffReg is a weakly supervised diffusion-based framework for multimodal deformable medical image registration. It integrates DINOv3 semantic guidance through gated cross-attention and anatomical supervision to support registration accuracy and deformation regularity.

The framework has been evaluated on three multimodal registration tasks:

1. CHAOS T1–T2 MR registration
2. L2R+AMOS22 abdominal CT–MR registration
3. μ-RegPro MR–TRUS registration
